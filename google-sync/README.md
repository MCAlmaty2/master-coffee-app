# 🔄 Синхронизация Google-таблиц → MasterCoffee CRM

Данные из двух Google-таблиц автоматически попадают в приложение каждые ~10 минут.
Ты вносишь цифры в Google как обычно — приложение обновляется само.

| Google-таблица | Скрипт | Куда в приложении |
|----------------|--------|-------------------|
| **Отчёт ежедневный месяц** | `daily-revenue-sync.gs` | Ежедневная выручка → факт «Выручка» в плане |
| **Отчёт ОП 2026** | `op-report-sync.gs` | Выполнение плана (товары: план/факт по неделям) |

---

## Как подключить (для каждой таблицы по разу)

1. Открой Google-таблицу.
2. Меню **Расширения → Apps Script**.
3. Удали то что там есть, вставь весь код из нужного `.gs` файла:
   - для «Отчёт ежедневный месяц» → `daily-revenue-sync.gs`
   - для «Отчёт ОП 2026» → `op-report-sync.gs`
4. Нажми **Сохранить** (💾).
5. Обнови вкладку с Google-таблицей — сверху появится меню **🔄 MasterCoffee**.
6. **🔄 MasterCoffee → Синхронизировать сейчас**. Google спросит разрешение —
   нажми «Разрешить» (один раз, для своего аккаунта).
7. **🔄 MasterCoffee → Включить авто (10 мин)** — дальше всё само.

---

## Правила, чтобы синхронизация не сломалась

- **Названия листов** — формат «МесяцГГ»: `Июнь26`, `Июль26`, `Август26`.
  Добавляешь новый лист на месяц → он сам появится в приложении.
- **Порядок колонок не менять:**
  - Дневной отчёт: `Дата · Сумма · Средний чек · Кол-во продаж · Рейс · Самовывоз`
  - ОП: `Товар · Месяц(план) · Неделя · День · недели… · ИТОГО · % · СТАТУС`
- **Названия товаров не менять** (Кофе (кг), Дрип, SAE/1 … — по ним идёт сопоставление).
- **Недели** (заголовки `01-07.06`…) можно менять — они подтянутся в приложение.

## После подключения

Когда синхронизация включена, **Google — источник правды**.
Вноси данные в Google; в приложении эти экраны показывают синхронизированные цифры.
Ручной ввод в приложении остаётся как запасной вариант (если Google недоступен).

## Безопасность

В скрипте используется публичный `anon`-ключ (он и так есть в приложении в браузере) —
это безопасно. Секретный (service) ключ нигде не используется.
