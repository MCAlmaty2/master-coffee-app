# Mastercoffee CRM — Telegram Mini App

CRM-приложение для отдела закупок и логистики, упакованное как Telegram Mini App.

**Стек:** React 18 + Vite + Tailwind + Supabase (Postgres + Realtime) + Telegram WebApp SDK.

## Быстрый старт

### 1. Установить зависимости

```bash
npm install
```

### 2. Настроить Supabase

Если ты получила архив с этим проектом — `.env` уже заполнен и Supabase уже подключён.

Если устанавливаешь с нуля — следуй инструкции в `supabase/SETUP.md`.

### 3. Стать первым админом

Открой `supabase/SETUP.md` → раздел «Шаг 6. Стать первым админом». В двух словах:

1. Узнай свой Telegram ID через [@userinfobot](https://t.me/userinfobot)
2. Зайди в приложение через бота — появится экран «Ожидайте подтверждения»
3. Открой Supabase → Table Editor → users → найди свою запись → role=admin, active=true
4. Через секунду приложение само пустит тебя как админа

### 4. Запустить локально

```bash
npm run dev
```

Откроется на http://localhost:5173.

Чтобы залогиниться в обычном браузере (не через Telegram), допиши в `.env`:
```
VITE_DEV_TELEGRAM_ID=твой-телеграм-id
```

### 5. Сборка для прода

```bash
npm run build
```

Готовая статика в папке `dist/`. Её нужно залить на любой HTTPS-хостинг (Vercel, Netlify, Cloudflare Pages).

## Подключение к Telegram

1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получи токен
2. У того же BotFather: `/newapp` → выбери бота → введи название, описание, иконку (640×360) и **URL твоего захостенного приложения**
3. Открой бота в Telegram → нажми меню — твой мини-апп запустится

## Как сейчас устроена база

| Сущность | Где живёт |
|---|---|
| Пользователи (`users`) | **Supabase** (общая база, realtime) |
| Прайс-лист (`products`) | **Supabase** (общая база, realtime) |
| Заявки, помол, списания, задачи, договоры | localStorage браузера (пока) |
| Уведомления внутри приложения | localStorage браузера (пока) |

На следующем этапе всё остальное тоже переедет в Supabase + добавятся RLS-политики.

## Структура

```
src/
├── App.jsx              ← основной файл приложения (~8000 строк)
├── main.jsx             ← точка входа
├── index.css            ← стили
└── supabase/
    ├── client.js        ← клиент Supabase
    ├── users.js         ← запросы по пользователям
    └── products.js      ← запросы по товарам

supabase/
├── schema.sql           ← SQL-схема для Supabase SQL Editor
└── SETUP.md             ← инструкция по созданию проекта

.env                     ← URL и ключи Supabase (НЕ коммитить!)
.env.example             ← шаблон .env (можно коммитить)
```

## Безопасность

- `anon` ключ Supabase — публичный по дизайну, можно вставлять в браузер
- `service_role` ключ — секретный, **никогда** не вставляй во фронтенд
- На этом этапе RLS-политики открытые (любой с anon-ключом читает данные). На следующем шаге их затянем
- `.env` лежит в `.gitignore` — в репозиторий не утечёт
