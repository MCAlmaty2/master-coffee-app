# Подключение Supabase — пошаговая инструкция

Эта инструкция написана для человека, который никогда не работал с Supabase.
В конце у тебя будет:

- Создан проект Supabase (бесплатно)
- Запущена SQL-схема из `schema.sql`
- На руках два ключа: **URL** и **anon key**
- Эти два значения нужно прислать в чат — я допишу подключение в код приложения.

Затраты: 15 минут, ничего платить не нужно. Бесплатного тарифа Supabase
хватит **с большим запасом** для команды на 20–50 человек.

---

## Шаг 1. Создать аккаунт Supabase

1. Открой [supabase.com](https://supabase.com)
2. Нажми **Start your project** (зелёная кнопка справа сверху)
3. Зарегистрируйся через **GitHub** (быстрее) или Email.
   Если регистрируешься через Email — Supabase пришлёт письмо для подтверждения.

> 💡 Аккаунт лучше делать **рабочий** или **корпоративный**, а не личный одного сотрудника.
> Если завтра этот человек уйдёт — доступ к базе уйдёт с ним. Можно сделать почту
> вроде `it@mastercoffee.kz` и регистрироваться на неё.

---

## Шаг 2. Создать проект

После входа ты попадёшь в **Dashboard**. Нажми **New Project**:

1. **Organization** — выбери (или создай новую, например «Master Coffee»)
2. **Project name** — `mastercoffee-crm` (любое имя)
3. **Database Password** — **сгенерируй пароль** кнопкой *Generate a password*
   и **сохрани его** (например, в менеджер паролей). Этот пароль может пригодиться
   позже, если будешь подключаться к базе напрямую.
4. **Region** — выбери **ближайший** регион. Для Казахстана подойдёт:
   - **Frankfurt (EU Central)** — стабильно, быстро
   - **Mumbai (AP South)** — географически ближе, но дольше пинг с Европы
   Обычно Frankfurt — оптимальный выбор для Казахстана.
5. **Pricing Plan** — **Free** (хватит надолго)
6. Нажми **Create new project**

Supabase будет создавать проект 1–2 минуты. Дождись зелёного индикатора готовности.

---

## Шаг 3. Запустить SQL-схему

В левом меню найди иконку **SQL Editor** (выглядит как `</>`).

1. Нажми **+ New query** (или кнопка «New SQL snippet»)
2. Открой файл `schema.sql` из папки `supabase/` в этом проекте
3. **Скопируй весь его содержимое** и вставь в редактор Supabase
4. Нажми зелёную кнопку **Run** (или **Ctrl + Enter**)

Ожидаемый результат: внизу появится сообщение **Success. No rows returned**.

Если будут ошибки — пришли мне скриншот, разберём.

### Проверить что таблицы создались

В левом меню → **Table Editor** (иконка с таблицей).
В списке таблиц должны появиться 11 штук:

- `users`
- `role_definitions`
- `products`
- `orders`
- `grind_requests`
- `tasks`
- `write_offs`
- `contract_requests`
- `notifications`
- `telegram_settings`
- `telegram_log`

Если всё это есть — отлично, схема развёрнута.

---

## Шаг 4. Получить URL и anon-ключ

В левом меню найди **Project Settings** (иконка шестерёнки внизу слева)
→ раздел **API**.

На этой странице тебе нужны **два значения**:

1. **Project URL** — выглядит так:
   ```
   https://xxxxxxxxxxxxxxxxxxxx.supabase.co
   ```

2. **Project API keys → anon (public)** — длинная строка вида
   ```
   eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.xxxxxxxx.yyyyyyy...
   ```

   ⚠️ **Внимание:** на той же странице есть второй ключ — **service_role**.
   Он секретный, его **никогда** не вставляй в фронтенд-код и никому
   не показывай. Нам нужен только **anon (public)** — он создан для
   браузера и не даёт никаких полномочий, кроме тех что разрешены через RLS.

---

## Шаг 5. Прислать значения в чат (только при ПЕРВОЙ настройке)

Эта инструкция актуальна для первой установки. Если ты уже получила обновлённый код — он уже включает интеграцию с Supabase, и шаг 5 можно пропустить.

Если устанавливаешь заново — пришли в чат:

```
SUPABASE_URL = https://xxxxxxxxxxxxxxxxxxxx.supabase.co
SUPABASE_ANON_KEY = eyJhbGci...очень длинная строка...
```

---

## Шаг 6. Стать первым админом

После того как код подключён к Supabase, чтобы получить доступ:

### Узнай свой Telegram ID

Открой бота [@userinfobot](https://t.me/userinfobot) в Telegram → отправь ему любое сообщение → он пришлёт твой числовой ID (например, `123456789`).

### Зайди в Mini App через Telegram

Когда приложение захостено и привязано к боту, открой его через бота → ты увидишь экран **«Ожидайте подтверждения»**. В этот момент в таблице `users` Supabase автоматически появляется запись с твоим Telegram ID и `role = pending`.

### Сделай себя админом через Supabase Table Editor

1. Открой Supabase → **Table Editor** → таблица **users**
2. Найди свою запись (там будет твоё имя из Telegram)
3. Двойной клик на ячейку **role** → впиши `admin` → Enter
4. Двойной клик на ячейку **active** → поставь галочку → Enter

Готово. Через 1–2 секунды мини-апп **сам подхватит изменение** и откроет тебе админ-панель — благодаря realtime-подписке. Перезагружать не обязательно.

После этого все следующие сотрудники, которые откроют бот, **автоматически** появятся в твоём админ-разделе «Запросы доступа» — ты их одобришь и назначишь роль. Больше в Supabase лезть не придётся, всё через приложение.

## Для разработки без Telegram

Чтобы залогиниться в обычном браузере (например, на localhost:5173), впиши свой Telegram ID в файл `.env`:

```
VITE_DEV_TELEGRAM_ID=123456789
```

После этого приложение само залогинит тебя как пользователя с этим Telegram ID.

**В продакшен `.env` эту переменную не вписывай** — иначе любой случайный посетитель сайта залогинится под тобой.

## Что дальше — следующий этап миграции

Сейчас в Supabase живут: **users + products**. Остальные сущности (заявки, помол, списания, задачи, договоры, уведомления) — пока в localStorage браузера, **то есть НЕ являются общими между сотрудниками**.

После того как ты убедишься, что Telegram-вход и общий прайс работают — на следующем шаге перенесём в Supabase **всё остальное**, и команда заработает полноценно. Также добавим тонкие RLS-политики, чтобы каждая роль видела только то, что положено.

## Что важно знать про бесплатный тариф

Supabase Free выдаёт:

- **500 МБ** базы данных — для CRM на несколько сотен заявок в месяц хватит на годы
- **1 ГБ** хранилища файлов (PDF, фото) — этого хватит на сотни документов
- **50 000 авторизованных пользователей в месяц** — нам столько и не нужно
- **2 ГБ** трафика в месяц — обычно достаточно
- **Неограниченное чтение/запись запросов**
- **Realtime** включён

Чего нет на Free:
- Если проект не используется **7 дней подряд** — Supabase его «паузит»
  (всё сохраняется, но временно недоступно). Восстанавливается одним кликом.
  Если у тебя будет реальная нагрузка — это не случится.

---

## Резервные копии

Supabase автоматически делает **ежедневные бэкапы** на платных тарифах.
На Free бэкапы тоже есть, но восстановить из них — только через поддержку.
Когда будешь готова — стоит апгрейднуть на **Pro ($25/мес)**, там добавляется
ежедневный point-in-time recovery. Это рекомендуется делать после того,
как накопится **минимум 1–2 месяца** реальных данных.

## Если что-то пошло не так

Самые частые проблемы:

**«Failed to create project»** — попробуй другой регион (например, AWS US East).

**SQL вернул ошибку «relation already exists»** — это нормально, значит
ты запускаешь схему повторно. Все таблицы используют `IF NOT EXISTS`, ничего
не испортится.

**Не вижу таблиц в Table Editor** — нажми кнопку обновить (`⟳`) в верхней
панели Table Editor; иногда нужно перезагрузить страницу.

**Не могу найти anon key** — проверь, что ты на странице Settings → API,
а не Settings → Database. Это разные страницы.

В любой непонятной ситуации — скриншот в чат, разберёмся.
